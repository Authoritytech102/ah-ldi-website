How this works: This dashboard is designed for a free Supabase backend. Until you connect your Supabase project in config.js, the public site runs in demo mode. Do not put private/service-role keys in browser files.

Dashboard Setup

1. Create a free Supabase project. 2. Run supabase_schema.sql in Supabase SQL Editor. 3. Put the project URL and anon/publishable key in config.js. 4. Open this page and sign in.
